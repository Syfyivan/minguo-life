# 民国人生 · 一套框架 · 六条命运线

一个「从出生到死亡」的时代人生模拟游戏的**叙事设计 + 可运行原型**。用同一套「事件链 / 选择 / 长期状态 / 交汇钩子」框架，承载 1912—1949 民国时代六种截然不同的出身命运。

**在线访问**：https://syfyivan.github.io/minguo-life/

## 页面地图

| 页面 | 内容 |
| --- | --- |
| `index.html` | 六出身命运总图（思维导图入口） |
| `minguo-life-design.html` | 设计基线：时代 / 城市 / 阶层 / 经济 / 社会制度调研，全部带史实可靠性分级 |
| `system-simulation.html` | 模拟系统层：日 / 旬 / 月 / 年 → 行动 → 点数 → 命运曲线，含 4 张 ECharts |
| `world-scenes.html` | **世界层**：生命阶段 → 地图分区 → 场景 → 每场景交互（行动/对话/抉择）+ 解锁条件 + 支线涌现，含解锁时间线与地图（从 `assets/world-data.js` 渲染） |
| `design-content.html` | **剧情设计层**：把剧情"做厚"的方法论与模板——事件六层解剖、剧情四源与密度规划、NPC 与关系账系统、"做厚"示例事件树、结局收束三元组、可直接填写的事件/NPC 生产模板与内容清单（纯设计文档，供自建游戏使用） |

| `action-tables.html` | 六出身完整行动表 + 数值平衡 + 门槛概率表（从 `assets/actions-data.js` 渲染） |

| `demo.html` | **纯文字 Demo（玩法验证版）**：选出身 → 每年安排若干事（精神/边际递减取舍）→「过完这一年」结算 → 年度历史事件 + 情境抉择 + 时代乘子冲击 → 命运曲线打点 → 一生总账与结局叙事。完全数据驱动，读取 `assets/` 三份数据，点按钮即可玩通一辈子 |
| `arc-01..06-*.html` | 六条完整人生线正文（佃农 / 士绅之女 / 纱厂女工 / 读书人 / 资本家之子 / 东北流亡者） |

## 关于史实

- 所有历史骨架（九一八、抗战、金圆券、包身工、二五减租、河南大饥荒等）均标注 **HI 权威 / MID 需核实 / LO 仅供方向** 三级可靠性。
- 六位主角**均为虚构角色**，仅用于承载真实史实，不对应真实人物。
- 游戏数值（属性点、概率系数、时代乘子）为**设计示意值**，正式写入前需试玩校准。

## 技术

纯静态 HTML，无需构建。图表用 ECharts（SVG 渲染）与 Mermaid，字体与库均本地内置于 `_shared/`，零外部依赖。
