# 民国人生 · 具体生活文字版

《民国人生》是一款从出生家庭出发，在时代冲击、谋生、关系与迁徙中逐年生活，直到主人公真实死亡的模拟游戏。

当前 `v0.7.12` 是完整人生文字验证版向 `design-v2.0.0` 迁移后的第十个家庭扩建版：它登记 18 类出生家庭、48 个人生领域和 8 种 1949 后承接，启用 schema 6 的领域、职业、岗位、雇佣、企业、股东、资产、债务、许可与特许账本，并能确定性迁移 schema 4/5 存档。当前真正可玩的内容是 13 个家庭、41 条路径和全部 8 种后半生去向；本轮新增汉口行栈、商号雇员与小商家，把受薪柜伙、仓栈理货与批发交接、干货小店三种人生做成从出生到死亡的具体生活。其余 5 个家庭注册项没有被伪装成已实装内容。

公开地址：<https://syfyivan.github.io/minguo-life/>

每局的结构为：

```text
出生家庭 → 成长 → 成年谋生 → 战争转折 → 战后重接
→ 1949 个人去向 → 中晚年谋生与关系 → 照料与记录
→ 主人公死亡发生 → 死亡确认 → 完整生平回收
```

可以逐年慢玩，也可以自动推进到下一次抉择。页面支持自动保存、手动存取和 JSON 导入／导出；旧版在 1949 结束的存档会继续进入 1950 年后的生活。

## 当前内容基线

- 13 个出生家庭
- 41 条主要成年谋生路径
- 8 种 1949 年后地域去向
- design-v2.0.0 的 18 类家庭、48 个人生领域和 8 种后半生承接已进入键注册表；其中未实装项不会出现在开局
- schema 6 会把旧 `routeKey` 兼容迁移为 `domainHistory[]` 与 `careerHistory[]`，并预留完整经济实体账本
- 当前场景、具名人物、史实节点、来源和审校状态分别进入统一索引；“自动回归通过”“已有来源”和“完成终审”保持为三种不同证据
- 170 个年度行动
- 139 组关键抉择、444 个关键选项
- 674 个作者生活与选择后果场景，其中 389 个会承接此前选择
- 7 组公共生活与政治参与抉择、21 个对应后果场景、41 个分路径公共联系人和 14 个重点史实节点
- 每个实际推进年份都有一段具体生活叙事
- 50、60、70、80 岁分别处理职业转换、关系、照料和人生记录
- 32 组地域／能力岗位原型；八种后半生去向都有具体岗位、工作地点、职责、结算办法、当年结果和下一步
- 41 条路径都有具体职业、单位、负责人、同事和客户／学生／病家，经营路线还会记录供应商、订单和改约
- 13 个家庭都有具名父母；父母会工作、谈话、衰老、去世并完成消息确认
- 西安修理铺、饭铺、上海洗衣缝补、广东侨乡小铺、广东沿海航运／客栈／小货、天津文具铺／成衣作坊与汉口行号／仓运小队／干货店选择会把企业、股东、资产、债务、许可或有限特许权益真实写入经济账本，不只改变叙事标签
- 上海劳工、东北工人、广东侨乡、广东沿海、天津与汉口商业路径按记录性别提供不同的现实职业资料：共享人生领域，但工作名称、单位和职责不会只换代词
- 广东侨乡线把家书、汇款通知、实际兑付、回执、地址和远方亲人状态分开；退信或断信不会自动生成死亡
- 广东沿海线把客票、货单、船期、床位、采购、损坏、交付和家人地址分开；拒绝不明包裹不会自动变成走私传奇
- 汉口线把船期、班组、车号、车租、空跑、锅灶、食客、赊账、欠薪、货损、工伤、洪水住处与战时地址分开；职业可以接触公开互助或政治组织，但不会因“码头工／车夫”身份自动入党或成为秘密工作者
- 天津线把介绍、报名、面谈、试工、录用／落选、商号单据、客户衣物、退件、房租与工具产权分开；基层职员身份不会自动变成编制、组织成员或秘密工作身份
- 汉口商业线把商号货、家庭库存、寄卖货、雇员工资、签字权限、担保、仓单、受潮、顾客坏账与合伙份额分开；受薪多年不会自动成为老板，小店经营也不会自动暴富
- 澳门经营线允许长期积累后进入旅运、住宿与娱乐配套企业，但不会把一次选择写成“赌王”，也不会冒充另一家真实历史承批公司
- 婚姻会形成具名配偶、共同生活办法、具体争吵以及和好、分居、迁移会合或异地生活的后果；也可以独身或没有子女
- 每局会记录具名疾病发作、求医／检查和每年的内心想法；成年人生至少能接触六名有独立生活的具名人物
- 晚年会停止固定工作，不会把同一岗位机械续写到死亡
- 终局包含出生、死亡、年龄、地点、原因、战争、迁徙、1949 去向、晚年、具名人物与未知事实

## 设计硬约束

- 出生家庭不等于人生路径
- 玩家只能决定自己能执行的行动，不能替母亲、配偶、子女、工友或同行者代签
- 不知道事件名称时仍会承受现实冲击
- 1949 只结束民国阶段，不结束主人公人生
- 主人公和其他主体的死亡都区分“发生”与“确认”
- 只有主人公真实死亡并完成确认后才能生成一生终局
- 终局只陈述事实，不用成功、失败、安稳或挣扎给人生排名
- 求职可以只找到短工或尚未留用，但当年必须写明具体岗位、结果、原因与下一步
- “结婚”“去香港”“经营”“生病”不能只是标签，必须产生人物、地点、现实事务、后果与当事人的想法
- 接触公共活动、申请加入政治组织与正式成为成员是不同状态；不参加、保持无党派或退出也是完整人生
- 秘密工作必须保留真实公开职业、家人知情边界和暴露后果；被捕问话只记录实际说了什么，不设置“忠诚值”或“叛徒”标签

## 验证

无需安装第三方依赖：

```bash
npm run verify
```

自动验证必须证明当前已实装的 13/13 家庭、41/41 路径、8/8 后半生去向都能跨过 1949 并走到真实死亡；具体职业、父母人生、婚姻后果、反复疾病、社会关系、每年心理记录、公共生活、政治身份过程、信息边界、企业账本、存档和事实终局同时成立。它不能被用来声称完整设计中的 18 个家庭与 48 个领域已经全部可玩。

## 产品边界

这版用于判断完整游戏设计在系统和文字内容上是否成立，可直接作为后续正式游戏的数据与制作蓝本。它不包含正式美术、音频、目标平台工程、外部史实终审和商业平衡；这些属于把设计制作成发行产品的后续工作，不属于本文字版的完成口径。
