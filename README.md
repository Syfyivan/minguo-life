# 民国人生 · 具体生活文字版

《民国人生》是一款从出生家庭出发，在时代冲击、谋生、关系与迁徙中逐年生活，直到主人公真实死亡的模拟游戏。

当前 `v0.7.0` 是正式设计的可执行文字验证版。除具体工作、家庭、疾病和心理生活外，它也把公共活动、政治组织申请、正式身份、公开服务、秘密联络、隐蔽工作、家庭知情和拘留压力接入同一生。1949 年仍是中段分水岭；人生随后进入大陆、香港、台湾、其他海外、继续流动或落点未定六种后半生，最终以死亡发生与确认结束。

公开地址：<https://syfyivan.github.io/minguo-life/>

## 当前可玩内容

| 出生家庭 | 成年谋生路径 |
| --- | --- |
| 苏北贫农家 | 留乡、进厂做工、士兵、难民／逃亡 |
| 江南沈家 | 读书人与公共写作者、新女性与教育工作者、举家流亡、医护与地方服务 |
| 上海工商家 | 实业继承、城市新女性、技术职员与独立营生 |

每局的结构为：

```text
出生家庭 → 成长 → 成年谋生 → 战争转折 → 战后重接
→ 1949 个人去向 → 中晚年谋生与关系 → 照料与记录
→ 主人公死亡发生 → 死亡确认 → 完整生平回收
```

可以逐年慢玩，也可以自动推进到下一次抉择。页面支持自动保存、手动存取和 JSON 导入／导出；旧版在 1949 结束的存档会继续进入 1950 年后的生活。

## 当前内容基线

- 3 个出生家庭
- 11 条主要成年谋生路径
- 6 种 1949 年后地域去向
- 76 个年度行动
- 53 组关键抉择、178 个关键选项
- 192 个作者生活场景，其中 126 个会承接此前选择
- 7 组公共生活与政治参与抉择、21 个对应后果场景、11 个分路径公共联系人和 11 个重点史实节点
- 每个实际推进年份都有一段具体生活叙事
- 50、60、70、80 岁分别处理职业转换、关系、照料和人生记录
- 24 组地域／能力岗位原型；六种后半生去向都有具体岗位、工作地点、职责、结算办法、当年结果和下一步
- 11 条路径都有具体职业、单位、负责人、同事和客户／学生／病家，经营路线还会记录供应商、订单和改约
- 3 个家庭都有具名父母；父母会工作、谈话、衰老、去世并完成消息确认
- 婚姻会形成具名配偶、共同生活办法、具体争吵以及和好、分居、迁移会合或异地生活的后果；也可以独身或没有子女
- 每局会记录具名疾病发作、求医／检查和每年的内心想法；成年人生至少能接触六名有独立生活的具名人物
- 晚年会停止固定工作，不会把同一岗位机械续写到死亡
- 终局包含出生、死亡、年龄、地点、原因、战争、迁徙、1949 去向、晚年、具名人物与未知事实

## 设计硬约束

- 出生家庭不等于人生路径
- 玩家只能决定自己能执行的行动，不能替母亲、配偶、子女、工友或同行者代签
- 不知道事件名称时仍会承受现实冲击
- 1949 只结束民国阶段，不结束主人公人生
- 主人公和其他主体的死亡都区分“发生”与“确认”
- 只有主人公真实死亡并完成确认后才能生成一生终局
- 终局只陈述事实，不用成功、失败、安稳或挣扎给人生排名
- 求职可以只找到短工或尚未留用，但当年必须写明具体岗位、结果、原因与下一步
- “结婚”“去香港”“经营”“生病”不能只是标签，必须产生人物、地点、现实事务、后果与当事人的想法
- 接触公共活动、申请加入政治组织与正式成为成员是不同状态；不参加、保持无党派或退出也是完整人生
- 秘密工作必须保留真实公开职业、家人知情边界和暴露后果；被捕问话只记录实际说了什么，不设置“忠诚值”或“叛徒”标签

## 验证

无需安装第三方依赖：

```bash
npm run verify
```

自动验证必须证明 3/3 家庭、11/11 路径、6/6 后半生去向都能跨过 1949 并走到真实死亡；具体职业、父母人生、婚姻后果、反复疾病、社会关系、每年心理记录、公共生活、政治身份过程、信息边界、存档和事实终局同时成立。

## 产品边界

这版用于判断完整游戏设计在系统和文字内容上是否成立，可直接作为后续正式游戏的数据与制作蓝本。它不包含正式美术、音频、目标平台工程、外部史实终审和商业平衡；这些属于把设计制作成发行产品的后续工作，不属于本文字版的完成口径。
