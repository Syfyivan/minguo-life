# 民国人生 · 文字版时代人生原型

《民国人生》是一款从出生家庭出发、在时代冲击中逐年形成生活路径的模拟游戏。

当前 `v0.4.0` 是完整一生设计的可执行验证版：三个出生家庭、九条路径、50 个年度行动、33 组关键抉择、96 个关键选项、105 个生活场景和事实型终局均由同一套状态机执行。

公开地址：<https://syfyivan.github.io/minguo-life/>

## 先从这里开始

- `demo.html`：当前文字版设计验证版
- `current-design.html`：当前设计总览
- `PROTOTYPE_STATUS.md`：已实现、未完成与发布边界
- `GAMEPLAY_SPEC.md`：运行时处理顺序与状态约束

## 当前可玩范围

| 出生家庭 | 可玩路径 |
| --- | --- |
| 苏北贫农家 | 留乡、进厂做工、士兵、难民／逃亡 |
| 江南沈家 | 读书人与公共写作者、新女性与教育工作者、举家流亡 |
| 上海工商家 | 实业继承、城市新女性 |

每局从出生推进到 1949 年：

```text
出生家庭 → 年度行动 → 普通生活 → 时代冲击
→ 关键抉择与主体回应 → 跨年事实账本 → 1949 去留
```

可以逐年慢玩，也可以自动推进到下一个抉择。页面会自动保存当前人生，并支持手动存取和 JSON 导入／导出。

## 设计硬约束

- 出生家庭不等于人生路径
- 角色换路径后不能变成另一个预设人物
- 母亲、父亲、配偶、家口、工友和外部门路拥有独立状态
- 死亡必须区分发生与确认
- 没有信息渠道时，只呈现生活冲击，不自动提供完整历史解释
- 终局只陈述事实，不做成功、失败、安稳或挣扎排名

## 其他页面

旧的六条人物线、行动表、世界层、情境表与模拟系统页面仍保留，用作历史设计素材与兼容展示。它们不再单独代表当前文字版运行时完成度。

## 史实边界

- 人物均为虚构角色
- 游戏数值和随机结果属于玩法设计，不等于历史事实
- 时代事件、制度名称、地区差异和具体数值在正式发行前仍需逐项史实审校
- 证据不足的制度细节与人物去向继续保留未知，不为完整感补写

## 正式制作边界

这版已经完成九条路线的完整一生设计和文字系统验证，可作为正式游戏的制作蓝本。它不是带美术、音频和商业调优的发行成品；正式产品仍需继续生产表现资产、新地域或家庭扩展、外部史实审校、目标平台工程和真实玩家调优。完整设计包位于 [民国人生设计仓库](https://github.com/Syfyivan/minguo-life-design-docs)。
